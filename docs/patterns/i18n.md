# Pattern: i18n formatting

`ui-detox/i18n` provides locale-aware number / date / unit formatting on top of
`Intl` — no bundle bloat — plus reactive message catalogs (`t()`, see below).

```ts
import { setLocale, registerUnit, fmt } from 'ui-detox/i18n';

setLocale('uk-UA');

registerUnit('g',    { symbol: 'г',    base: 1,    dimension: 'mass' });
registerUnit('mg',   { symbol: 'мг',   base: 1e-3, dimension: 'mass' });
registerUnit('mcg',  { symbol: 'мкг',  base: 1e-6, dimension: 'mass' });
registerUnit('kcal', { symbol: 'ккал', base: 1,    dimension: 'energy' });
```

Units sharing a `dimension` are inter-convertible and auto-scale together.

## Formatters

```ts
fmt.number(1234.5)                    // "1 234,5"
fmt.number(1234.5, { decimals: 0 })   // "1 235"
fmt.percent(0.82)                     // "82 %"
fmt.percent(0.821, { decimals: 1 })   // "82,1 %"
fmt.delta(12.3)                       // "+12,3"
fmt.delta(-4.5, { decimals: 1 })      // "-4,5"
fmt.qty(1234.5, 'mg')                 // "1 234,5 мг"
fmt.qty(1234.5, 'mg', { to: 'g' })    // "1,2 г"
fmt.qty(1234.5, 'mg', { auto: true }) // "1,2 г"  (best unit by magnitude)
fmt.qty(0.3, 'mg', { auto: true })    // "300 мкг"
fmt.date(iso)                         // "26 черв. 2026"
fmt.dateTime(iso)                     // "26 черв. 2026, 14:32"
fmt.relative(iso)                     // "2 години тому"
```

Auto-scale picks the unit where the value lands in `[0.5, 999]`.

## In templates

Call directly in an interpolation:

```html
<td>${fmt.qty(node.massNetoG, 'g')}</td>
<td>${fmt.qty(nutrient.amount, 'mg', { auto: true })}</td>
```

Or register filters and pipe:

```ts
import { registerI18nFilters } from 'ui-detox/i18n';
registerI18nFilters(); // number, percent, delta, qty, date, dateTime, relative
```

```html
<td>${node.massNetoG | qty:'g'}</td>
```

## Message catalogs (`t()`)

Per-locale nested message maps with a reactive locale, so `${t(...)}` bindings
re-render on locale switch — no template syntax, no `<Trans>` component.

```ts
import { registerMessages, setLocale, setFallbackLocale, t } from 'ui-detox/i18n';

registerMessages('en', enJson);    // { home: { heroTitle: '…', webDevFeatures: […] } }
registerMessages('uk', ukJson);
setFallbackLocale('en');           // used when a key is missing in the active locale
setLocale('uk-UA');                // shared with fmt.*; matches catalog 'uk' by subtag
```

- **Nested keys** — `t('home.heroTitle')` walks the dotted path.
- **Interpolation** — `t('greeting', { name })` fills `{{name}}`; unknown
  placeholders are left intact.
- **returnObjects** — a non-string value (array/object) is returned raw, feeding
  `<for>` directly.
- **Missing key** — tries the fallback locale, else echoes the key.

```html
<h1>${t('home.heroTitle')}</h1>                                   <!-- reactive text -->
<button title=${t('topBar.skip', { speed: 4 })}>☾</button>        <!-- reactive attr -->
<for each=${t('home.webDevFeatures')} item="f"><li>${f}</li></for> <!-- array -->
```

```ts
setLocale('en');   // every ${t(...)} and fmt.* on the page re-renders
```

Locale is a single reactive signal (`i18n.locale`), so `t()` and `fmt.*` always
agree; set it via `setLocale('en')` or `i18n.locale = 'en'`.

### `t` filter and back-compat

`registerI18nFilters()` also registers a `t` filter: `${'home.heroTitle' | t}`,
with params `${'greeting' | t:{name:'Роман'}}`. The legacy flat catalog still
works and takes precedence: `setCatalog({ 'recipe.emptyGraph': 'Порожній граф' })`.
